## Why lists matter

Dex223 only shows tokens from lists you enable. If a token is missing in Swap or Convert, check your lists first.

## Steps

1. Open **Token lists** from More → Product (or from the token picker).
2. On the **Lists** tab, enable the lists you trust.
3. Import a custom list by URL, JSON, or contract when needed.
4. On the **Tokens** tab, pin favorites or import a single token by address.

## Safety

Only enable lists from sources you trust. Malicious lists can surface scam tokens with familiar names.

## Overview

Token listing registers your token with a Dex223 autolisting contract so pools and the UI can discover it.

## Steps

1. Open **Token listing** from the main navigation.
2. Choose the listing contract and the token address (and ERC-223 twin if required).
3. Review fees and requirements for that list.
4. Confirm the listing transaction in your wallet.

## After listing

Create a pool and add liquidity so traders can get a quote. Use **Statistics** to confirm the pool appears once subgraph indexing catches up.
